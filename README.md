# Projeto Genius multiplayer para arduino
Projeto em C++ para arduino de jogo de memória (estilo Genius/Simon) para até 4 players

# Visão geral
O projeto foi desenvolvido para a disciplina de Design de Interfaces e Usabilidade [(relatório)]() e foi realizado em 3 etapas:

- [Design 3d do protótipo no Tinkercad]()
- Circuito para o arduino no Tinkercad, com o código deste repositório
- Prototipação na vida real, usando o Arduino Uno
