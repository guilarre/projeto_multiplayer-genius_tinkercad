# Projeto Genius multiplayer para arduino
Projeto em C++ para arduino de jogo de memória (estilo Genius/Simon) para até 4 players

# Visão geral
O projeto foi desenvolvido para a disciplina de Design de Interfaces e Usabilidade e foi realizado em 3 etapas:

1. [Design 3d](https://www.tinkercad.com/things/4REV07p06n0-genius-multiplayer-final?sharecode=d5hE2Wpx_3t9iIqHdENpJEUoV6rjGFDXADWt50j_-Xw) do protótipo no Tinkercad
2. [Circuito](https://www.tinkercad.com/things/01rVU7WXUt9-genius-arduino?sharecode=NNa2y8wgCgrfQRJKBhGxkDUTllHPgYrTHtufFcenDfo) para o arduino no Tinkercad, com o [código deste repositório](https://github.com/guilarre/projeto_multiplayer-genius_tinkercad/blob/main/genius_arduino_code/genius_game.cpp)
3. Prototipação na vida real, usando o Arduino Uno ([vídeo do protótipo em funcionamento](https://youtu.be/WCd8sRaAN5I))

[Relatório completo](https://github.com/guilarre/projeto_multiplayer-genius_tinkercad/blob/main/Relat%C3%B3rio%20prot%C3%B3tipo%20genius%20multiplayer.pdf)
